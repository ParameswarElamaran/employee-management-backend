Employee Management System Backend

Backend application built using Spring Boot and MySQL.

Features
REST APIs
CRUD Operations
MySQL Database
JPA/Hibernate Integration
Tech Stack
Java 21
Spring Boot
MySQL
Maven
API Endpoints
Get Employees
GET /api/employees
Add Employee
POST /api/employees
Update Employee
PUT /api/employees/{id}
Delete Employee
DELETE /api/employees/{id}
Run Project
mvn spring-boot:run
